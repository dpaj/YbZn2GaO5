# Data directory

## `data/neutron/CNCS_1d_scans/`

One-dimensional CNCS energy scans used for fitting and comparison. File names encode incident energy, temperature, field, and reciprocal-space position.

## `data/neutron/CNCS_2d_scans/`

Two-dimensional CNCS data products used for visual comparison to the fitted/preliminary model.

## `data/magnetization/`

Digitized magnetization-versus-field data.

Current file:

- `YZGO_MvB_black_curve_digitized_visible.csv`

## `data/cif/`

Crystallographic information file for YbZn2GaO5.

Current file:

- `ICSD_CollCode138765.cif`

## Notes

These data products are intended to support reproducible analysis scripts in `scripts/`. Large raw data and generated synthetic datasets may be handled separately from ordinary Git tracking.
